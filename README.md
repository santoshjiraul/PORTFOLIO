# Santosh Kumar Yadav — Portfolio

A responsive, editorial-style portfolio website for Santosh Kumar Yadav, Data Analyst.

## Included

- Responsive layout for desktop, tablet, and mobile
- Animated reveal sections on scroll
- Data-analyst themed visual dashboard cards
- About, toolkit, selected projects, and contact sections
- Mobile navigation menu

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Customize

Update the project descriptions, email address, and social links in `index.html`. Colors and layout variables are at the top of `styles.css`.
